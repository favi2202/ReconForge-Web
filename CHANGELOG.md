# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use semantic versioning.

## [0.2.0] - 2026-08-13

### Added

- Optional server-side URLScan Search API adapter for existing historical scan metadata; URL submission is deliberately not implemented.
- Optional server-side Shodan Host Search API adapter for existing service observations; on-demand scanning is deliberately not implemented.
- Provider-native scope compilation, structured subject-host enforcement, per-provider daily budgets, fixed-origin evidence links, and mocked integration/security tests for both adapters.

## [0.1.0] - 2026-08-13

### Added

- Local-first React planner with strict PSL-backed scopes and manual exact-domain lists.
- Fourteen typed reconnaissance packs, sensitive-review controls, query explanations, preview, deduplication, visual builder, and browser deep links.
- IndexedDB multi-project library with import, duplicate, recoverable deletion, synthetic demonstration, scoped manual result import, canonical normalization, provenance merging, grouping, filters, status, notes, tags, and false positives.
- JSON, CSV, Markdown, HTML, query-list, and scope-manifest exports with injection defenses.
- Optional authenticated Fastify owner API with strict scope/result policies, CORS, per-IP/principal/start/provider/concurrency quotas, deadlines, bounded responses, retries, cancellation, mock provider, and Brave Search adapter.
- Threat model, research comparison, ethical-use policy, disclosure process, deployment/provider/template guides, Docker packaging, GitHub Actions CI/Pages workflows, screenshots, and automated unit/integration/browser/accessibility coverage.
